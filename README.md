# Primespan: Personalised Longevity App (Landing Page)

A single-page website for a personalised longevity performance app, built for the persona **Natasha Lim**, a 38-year-old Senior Marketing Manager in Singapore who uses an Oura Ring and wants data-driven, personalised health guidance.

**Live site:** (https://fiasco-3007.github.io/primespan-longevity-app/)

## Persona motives
- Longevity optimisation
- Fear of illness
- Performance gains
- Self-sufficiency

## Features
- Interactive morning plan: tap actions to earn XP and raise predicted readiness
- "Can you hit a 90?" readiness simulator with live scoring
- Level ladder, streak counter and achievement badges
- Responsive layout, keyboard focus styles and reduced-motion support

## Tech
Plain HTML, CSS and JavaScript in one file (`index.html`). No build step or dependencies. Fonts load from Google Fonts.

## Notes
